# GUI assets - provenance & licensing

`widgets.png` (256×256) is the classic Minecraft Java Edition GUI sprite sheet
containing the hotbar (182×22 at 0,0) and the selection frame (24×24 at 0,22).

- **Pulled from:** InventivetalentDev/minecraft-assets (extracted vanilla assets),
  version 1.20.1 -
  `https://raw.githubusercontent.com/InventivetalentDev/minecraft-assets/1.20.1/assets/minecraft/textures/gui/widgets.png`
- **Browse other versions/files:** https://mcasset.cloud (by the same author)
- **Programmatic block textures:** the npm package `minecraft-assets`
  (PrismarineJS) exposes per-version block textures.
